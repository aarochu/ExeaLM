# Contributing to ExeaLM

Thanks for helping build ExeaLM. You do not need to have trained a model before.

## Getting started

1. Sign up so we can add you to the contributor list: https://docs.google.com/forms/d/e/1FAIpQLSdPHVZhuXxBDUf-cJM2zDbj1JZPsduu95Y_kTJ_g4gKAXdDVw/viewform
2. Read the [README](README.md) and the [Code of Conduct](CODE_OF_CONDUCT.md).
3. Look through the [open issues](https://github.com/exea-labs/ExeaLM/issues) and pick one labeled `good first issue`, or comment on one to claim it.
4. Fork the repo, create a branch, make your change, and open a pull request.

## Pull requests

- Keep each pull request focused on one thing.
- Describe what changed and why. For experiments, include the config, the baseline you compared to, and the result.
- Do not commit large data files, checkpoints, or anything under a restricted license. Link to the source instead.
- Never commit secrets, API keys, or personal information.
- A maintainer will review your pull request. Be patient, and be kind in review comments.

## Data contributions

Every dataset or filter we use needs a source link, a license, and a short note on what was done to it. If you cannot state the license, do not add the data.

## Credit

After your first merged contribution, add yourself to [CONTRIBUTORS.md](CONTRIBUTORS.md) in a pull request. Only list your name or handle if you are comfortable with it being public.
