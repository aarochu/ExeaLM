## Mix proposal v0 (1.98T tokens)

Written for a 2T-token pool. We train on about 100B tokens (see [DATA.md](../DATA.md)), so scale each bucket down by about 20 times and keep its share. [DATA.md](../DATA.md) also lists a second, English-heavier candidate mix and extra sources. Compare them with small ablations before choosing.

`python -m exealm.data.sources` prints it. In short:
- **Japanese, about 410B:** the cleanest LLM-jp Japanese, with Wikipedia, Aozora Bunko, KAKEN and Diet minutes seen
  several times.
- **English, about 970B:** FineWeb's best-scoring educational pages, plus books, papers and encyclopedias.
- **Math and code, about 210B.**
- **K2 Horizon, about 390B:** web and QA, plus reasoning and behavior data, mostly saved for the final decay phase.

Why it might be wrong, and therefore worth working on:
- Is about 21% Japanese right for a model this small? More Japanese makes it better at Japanese and worse at English.
  This is an experiment to run, not an opinion to hold.
- Repeating small high-quality sources (×2 to ×4) helps up to a point; past that the model memorizes them.
- We haven't counted K2 Horizon tokens yet, so those numbers are guesses.

## Pipeline (works on samples today)

```bash
# 1. download a sample
python -m exealm.data.download llmjp --subset ja/ja_wiki --max_files 1 --out data/raw
python -m exealm.data.download hf --repo IFM/TxT360-v2 --config web-high-medium --max_rows 20000 --out data/raw

# 2. filter + exact dedupe
python -m exealm.data.quality data/raw/*.jsonl.gz --out data/filtered

# 3. tokenizer (on a sample of the mix)
python -m exealm.data.tokenizer data/filtered/*.jsonl.gz --vocab 49152 --out tokenizer

# 4. pack into a flat token file with document boundaries (hold out a few files as validation)
python -m exealm.data.pack data/filtered/<train files> --tokenizer tokenizer --out data/packed/train
python -m exealm.data.pack data/filtered/<val file>    --tokenizer tokenizer --out data/packed/val

# 5. train on it
python -m exealm.train.pretrain --preset tiny --data data/packed/train --val data/packed/val --seq 256 --steps 2000
```

## Open data tasks

- Count tokens for each K2 Horizon subset (with our tokenizer once it exists, with any tokenizer until then).
- Near-duplicate removal across sources: MinHash LSH, for example with [datatrove](https://github.com/huggingface/datatrove).
- A quality classifier for Japanese, in the spirit of FineWeb-Edu's educational-value classifier.
- Decontamination: remove documents that contain our evaluation benchmarks.
- A curated **retrieval datastore** (a few billion tokens of reference text) for the RG circuits.
- **Team construction** for the agent board: which documents should share a board during pretraining
  ([memory.md](memory.md)).
- Scale the pipeline to 2T tokens: parallel, resumable, and it never writes the full corpus to a laptop.
